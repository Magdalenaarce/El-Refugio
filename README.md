# El Refugio — Bar · Cafetería · Talleres Creativos

Sitio web para el proyecto empresarial **El Refugio**, elaborado como parte del proyecto final de 2ª Dirección de Cocina.

## 🌿 Descripción

Web completa de una página (single-page) para El Refugio, un bar-cafetería cultural ubicado en C. República Dominicana 18, Las Palmas de Gran Canaria.

## 📁 Estructura

```
el-refugio/
├── index.html       # Toda la web (HTML + CSS + JS en un solo archivo)
├── netlify.toml     # Configuración de despliegue en Netlify
└── README.md        # Este archivo
```

## 🚀 Despliegue en Netlify

### Opción 1 — Arrastrar y soltar
1. Ve a [netlify.com](https://netlify.com) e inicia sesión
2. En el dashboard, arrastra la carpeta `el-refugio` al área de deploy
3. ¡Listo! Tu sitio estará en línea en segundos

### Opción 2 — Desde GitHub
1. Sube la carpeta a un repositorio de GitHub
2. En Netlify: **Add new site → Import from Git**
3. Conecta tu repo y despliega (sin necesidad de configurar nada más, el `netlify.toml` ya lo hace)

## 📋 Secciones incluidas

- **Hero** — Presentación visual con animaciones
- **Sobre Nosotros** — Historia, identidad y valores
- **La Carta** — Menú completo con tabs (Tapas, Bocadillos, Postres, Bebidas, Cervezas, Cócteles)
- **Actividades Culturales** — Música en directo, talleres, exposiciones
- **El Espacio** — Galería visual ilustrada
- **El Equipo** — Presentación de las promotoras
- **Reservas** — Formulario funcional de reservas
- **Mapa + Footer** — Ubicación y contacto

## 🎨 Tecnologías

- HTML5 · CSS3 · JavaScript Vanilla
- Google Fonts: Cormorant Garamond + Outfit
- Sin dependencias externas — funciona standalone
- 100% responsive (móvil, tablet, escritorio)
